# 未来シミュレーター V1.10.0

## V1.10.0 変更点
- 定期預金・貯蓄保険は満期月に、当月の積立・運用を反映して受取口座へ自動振替します。
- 満期受取額モードが「金額」の場合は設定した満期額を、利率モードの場合は満期時の評価額を払い出します。
- 満期後は契約資産を残高一覧から除外し、受取口座へ移します。
- 将来イベントに「定期預金・貯蓄保険の満期」を追加。契約資産、受取口座、任意の受取額を指定できます。
- 手動満期イベントと自動満期が同月に重複しないように処理します。
- アプリ表示、パッケージ、バックアップのバージョンをV1.10.0へ更新しました。
