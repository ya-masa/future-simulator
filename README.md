# 未来シミュレーター V1.11.0

## V1.11.0 変更点：資産不足時の自動補充
- 資金補充の優先順を現金→預貯金→換金可能な投資資産に統一しました。
- 自動資金補充と最低現金補充で、取り崩し不可の投資資産を除外します。
- 定期預金・貯蓄保険は途中解約可否、ロック期間、返戻金を確認します。
- 満期月の契約資産は満期処理で受取口座へ振り替えるため、同月の満期振替前に補充元として二重使用しません。
- 個別の将来イベント支出でも、ロック中または取り崩し不可の契約資産を直接引き落としません。
