# 未来シミュレーター V1.11.3

## V1.11.2 修正：未解消現金不足を利用可能資産から精算

- 前年度までの未解消現金不足に当年の新規不足を加え、当年の実質現金余剰で返済します。
- 返済額は現金・預貯金から実際に差し引き、資産残高との二重計上を防ぎます。
- 年次グラフ・概要カードは単純な不足発生累計ではなく、返済後の未解消不足残高を表示します。

## V1.11.0 実装：資産不足時の自動補充

- 現金→預貯金→換金可能な投資資産の順で補充。
- ロック中・解約不可の契約資産は補充元から除外。
- 購入イベント・契約開始時も全額資金確保後に成立。

## V1.11.3 修正：現金・預貯金の自動補充対象を個別設定

- 現金・預貯金の資産ごとに「自動補充・不足精算に使用する」チェックを追加。
- チェックを外した資産は自動補充および未解消現金不足の精算元から除外。
- 既存データで未設定の場合は、従来どおり対象（true）として扱います。
