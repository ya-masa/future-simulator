## v1.7.7 変更点

- データ管理画面のGAS連携に自動クラウド同期のON/OFF設定を追加しました。
- 自動同期を有効にすると、データ変更後の短い待機時間を経てローカルデータをクラウドへ送信します。連続入力時は送信をまとめます。
- 自動同期設定はブラウザごとに保存されます。GAS URL・アクセスキーも従来どおりブラウザ内に保存します。
- クラウドへの保存時は既存のrevision照合と楽観ロックを利用し、他端末の更新を検出した場合は自動同期を停止します。
- 初回接続でクラウドに既存データがある場合、自動上書きは行いません。先にクラウドから読み込んで同期基準を確立してください。
- ローカル保存を優先するため、画面の入力・編集はクラウド通信を待ちません。
- クラウドから読み込んだデータを直ちに再アップロードしないようにしました。
- 手動保存・読み込み・状態確認・明示的なローカル優先上書きは引き続き利用できます。

## v1.7.7 同期仕様と注意点

- 自動同期は「このブラウザのローカルデータ → Googleスプレッドシート」への自動送信です。クラウド側の変更を別端末へ自動ダウンロードする双方向同期ではありません。
- 別端末で更新した場合は、状態確認後に必要なデータをクラウドから読み込んでください。revisionが前回確認時と異なる場合は自動同期を停止します。
- GASウェブアプリURLとアクセスキーを設定し、データ管理画面で「自動クラウド同期を有効にする」をONにしてください。
- 自動同期をOFFにしても、IndexedDB／localStorageへのローカル自動保存は継続します。

- 基本の実効率は全期間の初期値として使用します。

## シナリオ計算仕様

シナリオの差分は、基本データに登録した標準条件に加算する年率の差（パーセントポイント）です。

初期値は次のとおりです。

| 条件 | 標準 | 楽観 | 悲観 |
|---|---:|---:|---:|
| 物価上昇率の差 | 0.0% | -0.5% | +1.0% |
| 投資利回りの差 | 0.0% | +2.0% | -2.0% |
| 給与等の増加率の差 | 0.0% | +0.5% | -0.5% |
| 年金改定率の差 | 0.0% | +0.2% | -0.5% |

- 標準シナリオは基本データをそのまま使用します。
- 物価上昇率の差は世帯標準率と個別支出の年間インフレ率に適用します。
- 投資利回りの差は現金・預金以外の資産に適用します。
- 給与等の増加率の差は年金以外の収入レコードに適用します。
- 年金改定率の差は年金収入レコードと人物情報の年金改定率に適用します。
- シナリオ計算は入力データのコピーに対して行うため、元の基本データは変更しません。
- 差分はシナリオ設定画面から変更できます。変更後は「再計算する」を実行してください。

## 注意事項・未実装

- シナリオは設定値を変えた条件比較であり、将来の結果や発生確率を保証するものではありません。
- 現在のシナリオは年率を一定差分で調整する方式です。景気循環、為替、株価変動、相関関係、モンテカルロ分析は未実装です。
- 税金・社会保険料はユーザーが入力した実効率による概算です。日本の法定税額・保険料を自動計算するものではありません。
- 自動取り崩しは売却手数料・譲渡益課税・売却時の価格変動を考慮していません。

## v1.3 Googleスプレッドシート連携

### 1. 保存先スプレッドシートを作る
Googleスプレッドシートを新規作成し、URLの `/d/` と `/edit` の間にある文字列をコピーします（スプレッドシートID）。

### 2. GASを設定する
1. スプレッドシートの「拡張機能」→「Apps Script」を開く。

### 保存仕様と注意

- アクセスキーはアプリを使うブラウザのlocalStorageに保存されます。個人用端末でのみ使用してください。
